# Changelog

## 1.0.0 (2026-03-04)

### Features

* Initial release of mcp-skeleton template
* Three runtime modes: stdio, HTTP, Cloudflare Workers
* Storage abstraction with in-memory and KV implementations
* Session management for HTTP/SSE transport
* Docker and docker-compose support
* CI/CD with conventional commits and release-please
* Comprehensive documentation and examples
